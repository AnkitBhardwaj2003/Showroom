# 🚗 Velocity X Garage

A modern and responsive car showcase website featuring Supercars, SUVs, and Sedans with interactive car details, stylish racing-inspired UI, and a fully mobile-friendly layout using HTML, CSS, and JavaScript.

🔗 Live Demo:
https://ankitbhardwaj2003.github.io/Showroom/

---

# ✨ Features

- Supercar, SUV, and Sedan sections
- Interactive About Car buttons
- Responsive mobile design
- Modern racing-style interface
- Contact section and footer
- Smooth navigation menu
- Mobile hamburger menu
- Car detail toggle system

---

# 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
